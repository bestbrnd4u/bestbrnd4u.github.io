# Бот-помічник у чаті

Чат на сайті тепер спершу відповідає бот — одразу, на кожне
повідомлення, мовою сторінки (українська, англійська, російська).
Без платної мовної моделі: він розуміє запит за ключовими словами.

## Що він уміє

- **Підібрати річ.** «Жіноча сумка до 8000», «годинник чоловікові в
  подарунок», «чорна сумка Coach», «окуляри Ray-Ban», «часы мужу до
  10 тыс». Розпізнає тип речі, для кого, бренд (і кирилицею —
  «коуч», «майкл корс»), колір і бюджет. Показує до чотирьох карток із
  фото, ціною й посиланням. Уточнення («до 5000», «а чорна є?»)
  доповнюють попередній запит. «Інші варіанти» гортає далі.
- **Відповісти на часте питання** — доставка, оплата, огляд перед
  оплатою, оригінальність, звідки речі, повернення, фізичний магазин,
  байєр-сервіс. Відповідь — **дослівно текст із розділу «Часті
  питання»** на відповідній сторінці сайту. Змінили текст на сторінці —
  бот після перезбірки відповідає вже новим.
- **Відповісти про товар, на сторінці якого пише людина**: «який
  розмір є?» (розміри в наявності й під замовлення), «а чорний є?»
  (прямо «так» чи «немає» й які кольори є), «скільки коштує?» (зі
  знижкою — і стару ціну), «коли отримаю?» (1–2 дні на відправку + 1–3
  дні Новою поштою, або строк під замовлення з картки), «з чого
  зроблена?», «які розміри сумки?», «це оригінал?». Усе — з картки
  товару; чого там немає, бот не вигадує, а передає вам.
- **Контакти й графік**: телефон, Telegram, Instagram, пошта — зі
  сторінки «Контакти».
- **Промокод**: де його ввести (кодів бот не роздає).
- **Опечатки в брендах**: «prda», «лакосте», «гучі».
- Нема сумок Prada — так і каже й показує, що в Prada є.
- **Неробочий час** (до 09:00 і після 20:00 за Києвом): передаючи
  розмову, каже, що менеджер відповість після 09:00.
- **Підказати, де стан замовлення**, і **покликати менеджера**.
- Кнопки-підказки: у порожньому чаті й під кожною відповіддю.

### Базові діалоги

Бот підтримує звичайну розмову, а не лише запити:

| Людина пише | Бот |
|---|---|
| «ок», «добре», «👍», «дякую», «так», «ні» | коротко відповідає, **вас не будить** |
| «до побачення», «гарного дня» | прощається |
| «як справи?» | відповідає й пропонує допомогу |
| «ти бот?», «ти людина?», «що ти вмієш?», «допоможіть» | пояснює, що вміє, і що менеджер поруч |
| «сервіс класний», «гарний магазин» | дякує |
| «як оформити замовлення?», «можна без реєстрації?» | кроки оформлення: кошик → дані → Нова пошта → оплата |
| «дорого», «а дешевше є?» | той самий запит, але дешевше за показане; немає — чесно каже |
| «не прийшла посилка», «де моя посилка» | посилання на перевірку **і** передає вам |
| «хочу скасувати замовлення», «сайт не працює», «не можу оплатити» | передає вам |
| скарга («жахливо», «обманули») | вибачається й передає вам |
| «доставляєте за кордон?» | передає вам (сам не обіцяє) |
| «а що з гарантією?» | посилання на умови гарантії й повернення |
| «привіт», «добрий день», «hi» | відповідає тим самим словом: «Привіт! 👋 Чим можу допомогти?» |
| «Привіт, хочу чорну сумку» | «Привіт! Ось чорні сумки — усього 22 варіанти, показую 4 👇» і картки з фото |
| «хочу штани», «є сукні?», «парфуми є?», «jeans» | «На жаль, штанів у нас зараз немає 😔» + кнопки з тим, що є |
| «туфлі», «чоботи», «босоніжки» | «Такого взуття немає, але є кросівки 👇» і одразу картки |
| «яка довжина ременя?» (на сторінці сумки) | з картки товару |

| «Tabby є?», «а Snapshot?», «GG0516S» | моделі з такою назвою |
| «кросівки 38 розміру» | лише ті, де є 38-й; немає — «40-го немає, є 36, 37, 38, 39» кнопками |
| «кросовки», «годиники», «окулари», «гаманец» | розуміє попри помилку |
| «найдешевші сумки», «найдорожчі годинники» | відсортовано |
| «скільки коштують годинники?», «скільки у вас сумок?» | «від 5 000 до 19 000 ₴, усього 24» і найдоступніші |
| «скільки коштує друга?», «а перша якого кольору?», «розкажіть про третю» | про товар із щойно показаної підбірки + посилання |
| «покажи схожі» (на сторінці товару) | той самий розділ, ціна поруч |
| «подарунок» | «для кого і на який бюджет?» кнопками; «подарунок мамі / другу» — одразу жіноче / чоловіче |
| «додайте в кошик» | як це зробити самому; «відкладіть для мене» — передає вам |
| пише російською на українській сторінці (або англійською) | відповідає мовою людини, посилання — на ту ж мовну версію |
| «шкіряна сумка», «з натуральної шкіри» / «веганська», «екошкіра» | лише справжня шкіра (не канвас зі шкіряним оздобленням) / лише екошкіра |
| «крос-боді», «шопер», «клатч», «маленька», «на ланцюжку», «бананка» | саме цей фасон; немає — «Рюкзаків зараз немає 😔» і інші сумки |
| «що краще, Coach чи Michael Kors?» | «обидва оригінал, вибір за смаком» і по дві сумки кожного |
| «є хтось?», «алло» | «Так, я тут! 🙂» |
| «ти мене не розумієш», «тупий бот» | вибачається й передає вам |
| «мій номер 067…, передзвоніть» | «менеджер передзвонить» — передає вам |
| «дайте знижку», «торг», «більше фото / відео», «опт», «коли поповнення» | пояснює, що це вирішує менеджер, і передає вам (на торг — ще й посилання на акції) |
| «працюєте в неділю?» | «щодня 09:00–20:00, без вихідних» |
| «можна приміряти?», «де ви знаходитесь?», «як підібрати розмір?» | з розділів «Часті питання»; про кнопку «Таблиця розмірів» |
| «замовлення 8689484479, телефон 067…» (номер **і** телефон) | бот сам перевіряє стан: «Передано в доставку» + номер накладної. Так само, як сторінка «Де моє замовлення»: номер і телефон мусять збігтися, ліміт звернень спільний |

| «розкажіть про другу» → «а розміри?» → «з чого вона?» | усе про ту саму річ, з посиланням |
| після підбірки «а розміри?» без номера | «Про яку з них?» + кнопки «Розкажіть про першу / другу…» |
| «скільки доставка і чи можна оплатити при отриманні?» | відповідає на кожне питання (до трьох), по черзі |
| «це оригінал?», «оригінал чи репліка?» | «Так, усі речі оригінальні» (раніше — «Ні.», бо на сайті це відповідь на «чи продаєте репліки?») |
| «як оплатити?», «оплата» / «чи можна оплатити карткою?» | без «Так.» на початку / з «Так.» — «так» чи «ні» лише на питання «чи…?» |
| «?» | «Так, я тут! Чим допомогти?» |
| «є знижка?» (на сторінці товару) | «Так, зараз знижка 30 %: 12 500 ₴ замість 17 900 ₴» (і до якої дати) або «знижки немає» + посилання на акції |
| «можна оплатити частинами?», «в кредит» | чесно: «краще уточнити в менеджера» — передає вам (розстрочки на сайті немає; якщо з'явиться — додайте автовідповідь, вона важливіша) |
| «ці годинники водонепроникні?» | передає вам: такого в картках немає |
| «у мене питання щодо замовлення» | просить номер і телефон — і перевіряє стан сам |
| «коли зателефонуєте?» | «менеджер звʼяжеться найближчим часом» — передає вам |
| «скільки чекати під замовлення?» | «строк свій у кожної речі — на її сторінці» |
| «де подивитися відгуки?» | «внизу сторінки кожного товару» |
| «що нового?» → «а зі знижкою?» → «найдешевші» | новинки → новинки зі знижкою → вони ж від найдешевшої |
| «годинник чоловіку» → «а з металевим браслетом?» | лише годинники на браслеті |
| «є сумки Prada?» → «а що є від Prada?» | усе від Prada, а не знову «сумок немає» |
| «покажіть ще», коли показано все | «Це всі — 3 варіанти» замість тієї ж підбірки вдруге |
| «скільки коштує друга?», а показано одну | про неї; показано дві, а питають про четверту — «Про яку з них?» |
| «що порадите?», «що популярне з годинників?» | спершу речі з вашою позначкою **HOT**, потім новинки, потім знижки. Відгуків поки немає — «найпопулярніше за продажами» бот не вигадує |

Коли бот не зрозумів і передає питання вам, у Telegram додається
підказка: «💡 Щоб бот відповідав на таке сам — адмінка → «Автовідповіді
бота в чаті»». Так ви вчите його на справжніх питаннях покупців.

На сторінці товару порожній чат одразу пропонує кнопки «Є в наявності?»,
«Які кольори?», «Покажи схожі». Поки бот думає — три крапки «друкує».

Підбірка звучить словами людини: «Ось чорні жіночі сумки Coach до
8 000 ₴ 👇», «Ще жіночі сумки — 5–8 з 39 👇».

Перевірено на корпусі з понад 70 живих фраз трьома мовами
(`tests/test-chat-bot.js`, розділ [11]); до цих правок бот влучав у
17 із 76, а «ок» і «дякую» передавав вам.

## Навчити бота новій відповіді

Адмінка → Налаштування → **«Автовідповіді бота в чаті»** → «Додати».

- **Ключові слова** — через кому, будь-якою мовою; досить початку
  слова: `розстроч, частинами, рассроч, installment`.
- **Відповідь українською** — обовʼязково. Англійською й російською —
  бажано: без них людині з `/en/` чи `/ru/` бот не відповідає
  українською, а передає питання вам.
- **Посилання** — необовʼязково, додасться рядком під відповіддю.

Ваші відповіді мають перевагу над вбудованими: напишете свою про
доставку — бот відповідатиме нею. Сайт перезбереться за кілька
хвилин, і бот підхопить нове (функція оновлює довідку раз на 10 хв).

Чого він не вміє — і не вдає, що вміє: оформлювати замовлення,
обіцяти знижки, відповідати про конкретне замовлення. Чого не
зрозумів, чесно каже й передає вам.

## Ви й бот

- **Ви бачите все в Telegram**, як і раніше: повідомлення покупця —
  зі звуком, відповідь бота — тихо, окремим повідомленням «🤖 Бот
  відповів».
- **Щойно ви відповіли самі** (реплаєм, як завжди) — бот у цій розмові
  замовкає.
- **Бот передав розмову вам** (людина попросила менеджера, скарга,
  скасування, «передзвоніть мені») — повідомлення приходить зі звуком і
  позначкою «⚠️ Бот передав розмову вам». Після цього бот у розмові
  мовчить.
- **Бот покликав вас, але відповідає далі** (не зрозумів питання,
  такої речі немає, торг, розстрочка, «відкладіть для мене», доставка
  за кордон) — теж зі звуком, з позначкою «⚠️ Потрібна ваша відповідь».
  Раніше бот у такому разі замовкав, і людина з наступним питанням
  («а зі знижкою?») чекала вас до ранку. Тепер на звичайні питання він
  відповідає й далі, а щойно напишете ви — замовкає.

## Що зробити один раз

1. **Оновити функцію** в Supabase: вставити
   `supabase/functions/telegram-order-bot/index.ts`, як зазвичай. До
   цього чат працює по-старому — лише ви.
2. **Викласти сайт** (Sync branches): бот бере каталог і питання з
   `data/chat-bot.json` на сайті.

Міграції бази не потрібно.

## Як вимкнути

Адмінка → Налаштування → «Листи покупцеві» → галочка **«Бот-помічник
у чаті на сайті»**. Зняли — після перезбірки (кілька хвилин) чат знову
лише ваш. Функція тримає довідку в памʼяті до 10 хвилин, тож
вимкнення може спрацювати з такою затримкою.
