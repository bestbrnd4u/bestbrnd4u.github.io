# Мова сайту за країною

Рішення власника 13.11.2026:

| Хто заходить | Що бачить |
|---|---|
| з України (будь-який браузер) | українську |
| з-за кордону, у браузері є **українська** | українську |
| з-за кордону, у браузері є **російська** (і немає української) | російську |
| з-за кордону, решта | англійську |
| хто сам обрав мову перемикачем | саме її, звідки б не зайшов |

Діє лише при **вході на сайт ззовні** (Google, Instagram, посилання). Переходи
всередині сайту мову не міняють. Пошукові боти не перенаправляються:
Google заходить зі США і мусить бачити українську версію.

## Два рівні

1. **Сайт сам** (уже працює, нічого налаштовувати не треба).
   Правило `assets/js/lang-rule.js` вписане в `<head>` кожної сторінки. Якщо
   мова відома одразу (обрана раніше, країну вже визначали), перехід стається
   до першого кадру. Якщо треба дізнатись країну, сторінка на мить
   лишається порожньою (не довше секунди) і відкривається потрібною мовою.
   Українська іноземцю не проблискує.

2. **Cloudflare** (налаштувати один раз — тоді іноземець навіть не завантажує
   українську сторінку, перехід ще швидший). Це два правила нижче.

## Як додати правила в Cloudflare

Cloudflare → ваш домен → **Rules → Redirect Rules** → **Create rule**
(Single Redirect). На безкоштовному тарифі доступно 10 правил, тут
потрібно два.

Для кожного правила:

- **If incoming requests match…** → **Custom filter expression** → **Edit expression** → вставити вираз;
- **Then…** → **Type: Dynamic**, **Expression** — з таблиці нижче;
- **Status code: 302** (тимчасове), **не 301**: постійне перенаправлення
  браузер запам'ятовує назавжди, і людина, що повернулась в Україну,
  далі потрапляла б на англійську;
- увімкнути **Preserve query string** (щоб `?brand=coach` не губився).

### Правило 1 — «Мова: російська за кордоном»

Вираз (If):

```
(ip.src.country ne "UA" and ip.src.country ne "XX" and ip.src.country ne "T1"
 and http.request.method eq "GET"
 and not lower(http.user_agent) contains "bot"
 and not lower(http.user_agent) contains "google"
 and not lower(http.user_agent) contains "bing"
 and not lower(http.user_agent) contains "yandex"
 and not lower(http.user_agent) contains "crawl"
 and not lower(http.user_agent) contains "spider"
 and not lower(http.user_agent) contains "lighthouse"
 and not lower(http.user_agent) contains "headless"
 and not lower(http.user_agent) contains "preview"
 and not lower(http.user_agent) contains "facebookexternalhit"
 and not http.cookie contains "bb-lang="
 and not http.referer contains "bestbrnd4u.com"
 and not starts_with(http.request.uri.path, "/en/") and http.request.uri.path ne "/en"
 and not starts_with(http.request.uri.path, "/ru/") and http.request.uri.path ne "/ru"
 and not starts_with(http.request.uri.path, "/assets/")
 and not starts_with(http.request.uri.path, "/data/")
 and not starts_with(http.request.uri.path, "/admin")
 and not starts_with(http.request.uri.path, "/cdn-cgi/")
 and not http.request.uri.path contains "."
 and not http.request.uri.path contains "%"
 and not lower(http.request.headers["accept-language"][0]) contains "uk"
 and lower(http.request.headers["accept-language"][0]) contains "ru")
```

Куди (Then → Dynamic → Expression):

```
concat("/ru", http.request.uri.path)
```

### Правило 2 — «Мова: англійська за кордоном»

Вираз — **той самий**, тільки останній рядок інший:

```
 and not lower(http.request.headers["accept-language"][0]) contains "ru")
```

Куди:

```
concat("/en", http.request.uri.path)
```

### Що означають рядки

- `ip.src.country ne "UA"` — не з України; `XX` — країну не визначено,
  `T1` — Tor: тоді нічого не робимо.
- рядки з `http.user_agent` — пошукові боти, перевірки швидкості, прев'ю
  посилань у месенджерах. (`cf.client.bot` на безкоштовному тарифі в
  правилах перенаправлення заборонене — перевірено 13.11.2026: «the use of
  field cf.client.bot is not allowed». `google` — бо службовий бот Google
  зветься Google-InspectionTool, без слова bot.)
- `http.cookie contains "bb-lang="` — людина вже обрала мову перемикачем
  (сайт пише цей cookie в мить вибору).
- `http.referer contains "bestbrnd4u.com"` — перехід усередині сайту.
- `/en`, `/ru` — уже мовна версія; `/assets/`, `/data/`, `/admin`, адреси з
  крапкою (файли: картинки, `feed.xml`, `robots.txt`) — не сторінки.
- `%` — старі кириличні адреси товарів: це переадресації на нові, у них
  немає мовних копій.
- `accept-language` — мова браузера. `uk` десь у списку → українська
  (правило не спрацьовує); `ru` → правило 1; решта → правило 2.
  (Поле `http.request.accepted_languages` у правилах перенаправлення
  Cloudflare недоступне — тому заголовок напряму.)

## Як перевірити

- З України — нічого не змінилось.
- З VPN (Польща, Німеччина) у вікні інкогніто → `bestbrnd4u.com/catalog`
  відкривається як `/en/catalog`. Із браузером російською — `/ru/catalog`.
- Перемкнути мову на українську → закрити вкладку → знову зайти з того ж
  браузера ззовні: лишається українська.
- Google Search Console → «Перевірка URL» для української сторінки — бот
  бачить українську (без перенаправлення).

Якщо щось не так — просто вимкніть обидва правила перемикачем у Cloudflare:
сайт однаково працює за першим рівнем.
