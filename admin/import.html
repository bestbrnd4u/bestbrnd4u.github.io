Масовий імпорт товарів

Заповніть один Excel-файл замість того, щоб додавати кожен товар вручну через форму. Інструмент перетворить рядки таблиці на файли товарів, готові для сайту.

1 Завантажте шаблон

Excel-файл із потрібними колонками та двома прикладами заповнення (товар з одним кольором і товар із двома). На другому та третьому листах файлу — довідники: точний список категорій сайту й допустимі значення для поля «Для кого».

2 Заповніть таблицю

У стовпцях із фото («Колір 1 (фото…)» тощо) для кожного товару можна писати або:

  • звичайну назву файлу — наприклад furla-1.jpg, furla-2.jpg — якщо фото лежать у вас на комп'ютері й ви завантажите їх у кроці 3 нижче;
  • або готове посилання на фото (https://…) — якщо фото вже десь розміщені в інтернеті. Тоді крок 3 можна пропустити.

Можна змішувати обидва варіанти навіть у межах одного товару.

3 Завантажте фото (необов'язково)

Якщо у таблиці вказували назви файлів, а не посилання — виберіть тут одразу всі відповідні фото з комп'ютера (можна виділити багато файлів одразу). Інструмент сам підставить потрібне фото до потрібного товару за назвою файлу.

6 Що робити з архівом далі

Archів вже має правильну структуру папок усередині (data/products/…, а фото — у assets/images/products/uploads/…), тому:

  • Розпакуйте архів прямо в папку вашого репозиторію на комп'ютері (туди, де лежить data, assets тощо) — файли самі стануть в потрібне місце, поверх існуючих товарів нічого не перезапише.
  • Відкрийте GitHub Desktop — побачите нові файли в списку змін.
  • Напишіть коротке повідомлення коміту (наприклад «Імпорт товарів») і натисніть Commit → Push origin.
  • Через 1–2 хвилини GitHub Actions сам збере всі товари в загальний каталог сайту — товари з'являться на сайті автоматично.
  • Після цього товари також з'являться в адмінці (розділ «Товари») — за потреби доповніть чи виправте щось вручну, як завжди.
Один файл фото можна використати для кількох товарів одразу — просто вкажіть його назву в кількох рядках таблиці, завантажувати повторно не потрібно.
